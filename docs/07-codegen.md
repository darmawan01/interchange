# 07 — Codegen and plugins

One `generate` produces every binding and every client. The generators are
[pluggable](10-extensibility.md); the ones below are what ships in the box — and none of them is
privileged, which is the test of whether the extension point is real.

## The pipeline

```
  any source format          canonical proto            outputs
  ─────────────────          ───────────────            ───────
  .proto        ─┐
  OpenAPI 3.x   ─┤ frontend                          ┌─ Go types + server ifaces
  JSON Schema   ─┼─ adapters ─▶  FileDescriptorSet ─┼─ TS types + browser clients
  GraphQL SDL   ─┤   (§09)          (the IR)         ├─ bus subscribers + clients
  Interchange   ─┘                                   ├─ permission table (optional)
  DSL                                                └─ CLI command tree
```

Everything downstream of the IR is format-blind. A generator never learns whether the contract
started life as proto or OpenAPI.

> **`protoc-gen-bus` emits no subscribers.** It was going to, and that was wrong: the message
> engine subscribes from the registry, so the generated `ServiceDesc` *is* the subscriber. A
> generated subscription alongside it would be a second source of truth for the same fan-out — and
> the annotation would then have two readers that could disagree.

## The generators that ship

| Generator | Emits | Source |
| --- | --- | --- |
| `protocolbuffers/go` + `connectrpc/go` | messages, server interfaces, HTTP clients | upstream |
| `bufbuild/es` + `connectrpc/es` | TypeScript types and browser clients | upstream |
| `protocolbuffers/python` | message classes; transport is ~80 lines by hand | upstream |
| **`protoc-gen-bus`** | the service descriptor, the server interface, and typed bus clients, from `(transports)` | ours |
| **`protoc-gen-authz`** | the permission table; fails the build on a bad annotation | ours — **optional**, ships with the `/auth` module |
| **`protoc-gen-cli`** | a Cobra command tree from `(cli.command)` | ours |

```yaml
# buf.gen.yaml
version: v2
clean: false
inputs: [{directory: api}]
managed:
  enabled: true
  disable:
    - {file_option: go_package, module: buf.build/googleapis/googleapis}
  override:
    - {file_option: go_package_prefix, value: github.com/<org>/platform/gen/go}
plugins:
  # pin every version; write down WHY next to any pin that is held back
  - {remote: buf.build/protocolbuffers/go, out: gen/go, opt: [paths=source_relative]}
  - {remote: buf.build/connectrpc/go,      out: gen/go, opt: [paths=source_relative]}
  - {remote: buf.build/bufbuild/es,        out: gen/ts, opt: [target=ts]}
  - {remote: buf.build/connectrpc/es,      out: gen/ts, opt: [target=ts]}
  # local plugins: built into ./bin before generate.
  # strategy: all -- each needs the WHOLE tree in one invocation.
  - {local: bin/protoc-gen-bus,   out: gen/go/bus,   strategy: all}
  - {local: bin/protoc-gen-authz, out: gen/go/authz, strategy: all}
  - {local: bin/protoc-gen-cli,   out: gen/go/cli,   strategy: all}
```

## Writing a plugin

A protoc plugin reads a request on stdin and writes generated files on stdout. In Go, `protogen`
reduces that to about fifteen lines of scaffolding.

```go
func main() {
    protogen.Options{}.Run(func(p *protogen.Plugin) error {
        p.SupportedFeatures = uint64(pluginpb.CodeGeneratorResponse_FEATURE_PROTO3_OPTIONAL)
        return run(p)
    })
}

func run(p *protogen.Plugin) error {
    var rules []Rule
    for _, file := range p.Files {
        if !file.Generate {
            continue // p.Files includes every transitive import
        }
        for _, svc := range file.Services {
            for _, m := range svc.Methods {
                // NOT m.Desc.Options() -- a descriptor built by anything
                // other than linked generated Go carries custom options as
                // dynamicpb values, and GetExtension against those panics or
                // silently returns the zero value. An annotation that reads
                // as absent is a check that stops firing.
                opts := interchange.MethodOptions(m.Desc)
                a, _ := proto.GetExtension(opts, authv1.E_Auth).(*authv1.AuthOptions)
                if a == nil && cfg.OnMissing == Error {
                    // This module's default policy -- not a core rule.
                    return fmt.Errorf("%s: missing (auth) annotation", m.Desc.FullName())
                }
                if !a.Public && !known(a.Permission) {
                    return fmt.Errorf("%s: unknown permission %q", m.Desc.FullName(), atom(a.Permission))
                }
                rules = append(rules, ruleFor(svc, m, a))
            }
        }
    }
    sort.Slice(rules, func(i, j int) bool { return rules[i].Procedure < rules[j].Procedure })

    g := p.NewGeneratedFile("table.go", "github.com/org/platform/gen/go/authz")
    g.P("// Code generated by protoc-gen-authz -- DO NOT EDIT.")
    // ... emit the sorted table ...
    return nil
}
```

## Five rules for plugin authors

| Rule | Why |
| --- | --- |
| **guard on `Generate`** | Without it you emit code for `google/api/annotations.proto`. |
| **`strategy: all`** | By default buf invokes a plugin once per directory. Anything emitting a cross-cutting registry needs the whole tree in one pass. |
| **sort before emitting** | Go map iteration is random. A shuffled generated file fails the drift check every other run and nobody trusts the gate after that. |
| **fail, don't warn** | When your plugin's policy says an input is invalid, return an error. A warning in a build log is a warning nobody reads. |
| **deterministic headers** | No timestamps, no version strings that change per build — same input, same bytes. |
| **read options through core** | `interchange.MethodOptions`, never `Descriptor.Options()`. Both plugins ship a mutation test that fails with *"an annotation was read as absent"* when someone reverts this. |

## The gate that makes it real

```makefile
plugins:
	go build -o bin/protoc-gen-bus   ./cmd/protoc-gen-bus
	go build -o bin/protoc-gen-authz ./cmd/protoc-gen-authz
	go build -o bin/protoc-gen-cli   ./cmd/protoc-gen-cli

generate: plugins ; ix generate
lint:     ; ix lint
format:   ; ix fmt
breaking: ; ix breaking --against 'origin/main'

# Generated output is COMMITTED. This is what makes that true rather
# than aspirational -- and it is the whole reason the contract cannot drift.
verify: generate
	@git diff --exit-code -- gen/ \
	  || (echo "generated output is stale: run 'make generate'"; exit 1)
```

`ix verify` wraps this — see [§11 The CLI](11-cli.md).
